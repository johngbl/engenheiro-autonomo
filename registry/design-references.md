## Usage Protocol

1. Before starting UI work, consult relevant categories above.
2. Fetch 2-3 references that match the project's aesthetic direction.
3. Extract patterns (layout, color, typography, motion) - never copy wholesale.
4. Apply the Anti-Slop directive: synthesize references into something purposeful and distinct.
